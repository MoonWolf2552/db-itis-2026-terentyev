# 🚗 AutoService DB — База данных автосервиса

## О проекте

**AutoService DB** — это учебный проект по проектированию реляционной базы данных
для автоматизации работы небольшого автосервиса. Предметная область охватывает
учёт клиентов и их автомобилей, оформление заказов на ремонт и обслуживание,
а также распределение работ между мастерами и услугами (ТО, диагностика,
шиномонтаж и т.п.).

Основная проблема, которую решает проект, — замена «ручного» ведения журнала
заказов (бумажные записи, Excel-таблицы, разрозненные данные) на единую
структурированную базу данных. Это позволяет быстро находить историю
обслуживания конкретного автомобиля, видеть загрузку мастеров, рассчитывать
стоимость заказа по прайсу услуг и избегать потери или дублирования информации
о клиентах и их обращениях.

В рамках проекта спроектирована ER-диаграмма в нотации Crow's Foot, выделены
5 основных сущностей (Клиент, Автомобиль, Заказ, Услуга, Мастер) и составлены
запросы на реляционной алгебре.
